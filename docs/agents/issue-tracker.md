# Учёт задач

Единственный источник задач и статусов — корневой `TODO.md`.

Скиллы Мэтта используют его вместо GitHub Issues и отдельных файлов задач. Упоминания issue tracker и tickets в скиллах относятся к задачам в `TODO.md`, а не к дополнительной очереди.

Одновременно выполняется одна задача. Сохранять порядок ожидающих задач и прежние записи. Пользователь выбирает цель; перед реализацией согласовать границы и проверки. Завершать задачу после выполнения согласованных проверок; конкретные внешние препятствия отмечать как блокировку.

Категории triage описывают готовность запроса и не заменяют статусы выполнения в `TODO.md`.
