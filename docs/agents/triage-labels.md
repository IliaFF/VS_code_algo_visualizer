# Категории triage

| Категория скиллов Мэтта | Категория проекта | Значение |
| --- | --- | --- |
| `needs-triage` | `needs-triage` | Запрос требует разбора |
| `needs-info` | `needs-info` | Не хватает сведений от автора запроса |
| `ready-for-agent` | `ready-for-agent` | Задача определена и готова к выполнению агентом |
| `ready-for-human` | `ready-for-human` | Выполнение требует участия человека |
| `wontfix` | `wontfix` | Принято решение не выполнять запрос |

При необходимости указывать категорию в тексте задачи в `TODO.md`. Это характеристика запроса, а не отдельный статус выполнения и не вторая очередь.
