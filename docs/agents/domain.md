# Термины и проектные решения

Проект использует единый контекст: корневой `GLOSSARY.md` и решения в `docs/adr/`.

Перед исследованием кода читать `GLOSSARY.md`, если он существует, и решения из `docs/adr/`, относящиеся к текущей задаче. Отсутствие этих документов не мешает работе.

Использовать согласованные термины из словаря. Создавать или дополнять словарь по мере согласования терминов, а ADR — по мере согласования значимых, трудно обратимых решений. Пустые документы заранее не создавать.

Если предложение противоречит существующему ADR, явно указать противоречие и согласовать пересмотр решения.
