# Geometry — схема рядом с кодом

Расширение показывает подготовленные агентом графы алгоритмов, объяснения и свойства рядом с исходником. Выбор узла ведёт к коду, курсор в однозначном диапазоне выбирает узел. Расширение само не анализирует код, не обращается к ИИ и не запускает верификатор.

## Установка без сборки

Требуется VS Code **1.85 или новее**. Установка VSIX не требует Node.js, npm, Python, C++-компилятора или дополнительных расширений.

1. Откройте [последний GitHub Release](https://github.com/IliaFF/VS_code_algo_visualizer/releases/latest) и скачайте файл `geometry-diagrams-<версия>.vsix` из Assets. Архивы Source code — не установочные пакеты.
2. В VS Code откройте Extensions → … → **Install from VSIX…** и выберите скачанный файл. При необходимости выполните предлагаемое самим VS Code действие перезагрузки.
3. Если код открыт через WSL/SSH/Dev Container, установите расширение в соответствующем удалённом окружении через Extensions. Оно работает на стороне workspace.

Идентификатор расширения — `local-geometry.geometry-diagrams`. Он сохранён для обновления прежней локальной версии 0.1.0. Пакет распространяется через GitHub, не Marketplace; подпись издателя Marketplace отсутствует. Устанавливайте только доверенный файл. Для проверки загрузки сравните его SHA-256 с `SHA256SUMS` в том же Release; совпадение проверяет целостность, но не заменяет доверие к источнику.

Автоматическое обновление из Marketplace не настроено: новую версию устанавливают из нового VSIX.

## Первый запуск с готовым geometry

1. Скачайте исходники **того же тега Release** и распакуйте их отдельно. Это нужно только для готового примера; для своего проекта исходники расширения не требуются.
2. Через File → Open Folder откройте `examples/geometry` из распакованного проекта. Корнем должна быть именно эта папка, не корень репозитория. Решение о Workspace Trust принимайте только для знакомого проекта; в недоверенном workspace расширение отключено.
3. Откройте палитру команд и выполните **«Анализ агента: Открыть JSON рядом с кодом»** (`analysis.openDocument`). Выберите `analysis.json` из открытой папки.
4. Начните с обзора, выберите модуль и операцию. Откройте её отдельное объяснение, раскройте блоки или нажмите **«Все подробно»**. **«Показать участок кода»** ведёт к исходнику.

Пример не встроен в VSIX: он поставляется в исходниках релиза. Новая команда для его открытия не добавлялась. C++ из примера читается как текст, не компилируется и не исполняется.

Для нового JSON geometry используется именно команда анализа агента. Старая команда **«Geometry: Открыть схему рядом с кодом»** (`geometry.openDiagram`) открывает прежние укрупнённые описания, а не новый `analysis.json`.

## Работа со своим проектом

Откройте папку целевого проекта и попросите своего агента подготовить JSON v1 по [скиллу algo-extension](https://github.com/IliaFF/VS_code_algo_visualizer/blob/main/.pi/skills/algo-extension/SKILL.md) и [контракту формата](https://github.com/IliaFF/VS_code_algo_visualizer/blob/main/docs/specs/agent-analysis-format.md). Скилл — инструкция внешнему агенту, не функция генерации внутри расширения; VSIX не устанавливает скилл в ваш проект.

Затем выполните `analysis.openDocument` и выберите JSON. Пути в нём относительны выбранному корню workspace, а не каталогу JSON. В multi-root расширение предложит выбрать корень. Поддерживаются файловые workspace (`file:`).

После сохранения новой версии JSON нажмите **«Перезагрузить анализ»**. Наблюдения за файлом нет. При ошибке обновления остаётся последняя корректная версия с предупреждением. Расширение не сохраняет JSON или исходники за пользователя.

## Если что-то не открылось

- **Команды нет:** проверьте версию VS Code, включение расширения и место установки (локально или в WSL/SSH/контейнере), затем Workspace Trust.
- **Путь или файл недоступен:** проверьте корень проекта. Выход наружу, в том числе через символьные ссылки, запрещён.
- **Хеш не совпал:** анализ мог устареть; несохранённый буфер тоже учитывается. Совпадение хеша не доказывает правильность объяснения.
- **Якорь не найден или неоднозначен:** обновите привязки в анализе. При пересечении диапазонов обратный выбор не угадывает узел. В geometry повторяющиеся возвраты имеют контекстные якоря с этим ограничением.

Анализ geometry и пакет прошли локальные самопроверки. Они не доказывают математическую корректность C++, численную устойчивость или работу пакета в конкретном пользовательском окружении. Новый анализ и установка VSIX требуют отдельного живого просмотра пользователем; ранее принятый интерфейс этим не отменяется.
